# test

Тестовый репозиторий для отработки работы с GitHub: веток, коммитов и pull request'ов.

## Как внести изменения

1. Создайте ветку от `main`: `git checkout -b my-change`
2. Внесите правки и закоммитьте их: `git commit -am "Описание изменений"`
3. Отправьте ветку на GitHub: `git push -u origin my-change`
4. Откройте pull request в `main` и дождитесь ревью.
